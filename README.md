# 🐍 Python Web Scraping & Data Automation Suite

A collection of standalone, production-ready Python utility scripts designed to extract public web content and instantly repair corrupted spreadsheet lead lists.

## 🛠️ Tools Included

### 1. Advanced CSV Data Cleaner
Fixes common formatting issues introduced by clunky web scrapers or Excel data views:
* Expands broken scientific notation numbers (e.g., changing `2.08E+09` back into complete phone digits).
* Unlocks hidden date parameters trapped behind hashtag formatting (`########`).
* Strips messy blank margins and truncates column rows to make databases uniform.

### 2. Automated Daily Scraper & Discord Notifier
Crawls target public directories using `urllib` and `BeautifulSoup` to capture structural text blocks and push updates instantly to your team's Discord channels.
